# Consistent HMIS workspaces

The shared `AcKpiCardComponent` provides the same label → value → context reading order across Patients, Doctors, Appointments, OPD, IPD, Laboratory, Pharmacy, Inventory, Billing, the hospital dashboard, Reports, MIS and Quality. Queue shortcuts use real buttons with keyboard focus and retain the module's existing navigation. Informational figures are articles, not nonfunctional buttons.

`workspace-design.css` aligns headers, actions, module tabs, panels, tables and focus treatment. The administration pages use the same workspace headings. Blue and purple are the Auspira brand colors; teal/green, amber and red retain their operational meanings. Theme tokens support dark mode. Tables and long tab bars scroll within their own containers, while the page remains within the viewport.

KPI grids adapt to available width and use two columns on phones, falling back to one on very narrow screens. Full currency amounts stay intact and scale to fit their cards. Icons are decorative, labels stay visible, and data loading is represented by an em dash rather than a fabricated zero.

The figures continue to come from the existing branch-scoped services. Registry cards describe their data context; appointment counts explicitly refer to loaded records where appropriate. No clinical findings, statistics or financial transactions are generated by the redesign.

Emergency and other modules using the unconnected workspace now show unavailable metrics and a clear connection status. The former hardcoded figures, sample records and success-only action popups have been removed. This does not implement an Emergency workflow.

Validation:

- `npm run build`
- `node --test tests/*.test.cjs`
- `node tests/workspace-ui-browser.cjs` (requires Playwright and a server on port 4217; override with `WORKSPACE_BASE_URL`)
- `tests/responsive-browser.cjs` checks the shell, navigation and broader page layouts.

The workspace browser checks cover 360, 768, 1366 and 1920 pixels, KPI number wrapping, card clipping, queue navigation, replenishment filtering and dark mode. A targeted contrast check verifies dark surfaces and readable Laboratory headings and critical alerts. The Laboratory's legacy dark styles now use surface tokens for backgrounds and text tokens for foregrounds. Local browser fixtures never write production records. Screenshots and results are saved under `artifacts/workspace-ui` for visual review.
