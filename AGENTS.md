# Care360 frontend instructions

The user's standing requirement is to preserve the existing design standards in every feature and phase: brand colours, Inter typography, spacing, shared controls, responsive layouts and interaction patterns.

Before changing UI, read `docs/DESIGN-STANDARDS.md`, the applicable global styles and a neighbouring established module. Reuse theme tokens and shared components instead of defining a new feature palette or font. Verify touched UI in light/dark themes and desktop/mobile layouts, with synthetic data for previews. Include design consistency in completion checks and distinguish preview validation from hospital UAT.

Preserve clinical behaviour, branch scope, permissions and workflow API values during presentation changes.
